# injurybug
*Injury data scraper from official CFB resources.*

Now that every FBS conference officially publishes their injury reports for in-conference games, this repository serves to automatically scrape and serve users updated injury reports from every FBS conference. All data will be mirrored to this GitHub repository and is intended to be hosted using a free Cloudflare D1 database and GitHub pages to eliminate recurring costs of hosting.

Due to the limitations of conference reporting, it is impossible to get injury data for non-conference games.
